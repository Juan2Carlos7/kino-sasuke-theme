# Sasuke Uchiha — Tema para Kino TV

Tres temas inspirados en Sasuke Uchiha para Kino TV, con logo Sharingan + SASUKE:

- **Sasuke Uchiha** — negro y rojo Sharingan
- **Susanoo** — morado
- **Chidori** — azul eléctrico

## Instalar

En Kino (0.9.81 o más nuevo): Ajustes ▸ Plugins y pega:

```
https://raw.githubusercontent.com/Juan2Carlos7/kino-sasuke-theme/main/kino-plugin.json
```

O escribe `Juan2Carlos7/kino-sasuke-theme` en el buscador de plugins.

Después elige el tema en Ajustes ▸ Apariencia.
